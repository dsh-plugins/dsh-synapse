# 群聊背景窗口与主动回复机制

本文档说明 QQ 群聊背景持久化、图片缓存、概率回复、词云加权、空闲消息与状态恢复的实现细节。

## 背景窗口与持久化屏障

- **独立事务入库**：已启用聊天的 QQ 群在 `<profile>/data/dsh-synapse/chat-state.sqlite` 中独立保存最近 100 条未触发的普通消息，每条入站消息在独立 SQLite 事务内按 `(group_id, message_id)` 去重并写入。
- **按批领取与确认**：当消息触发回复（@、关键词、概率命中或空闲事件）时，宿主将当前未提交的背景消息与触发消息绑定为同一个 `claimed` 批次，一并送入当前群的 DSH 原生会话。
- **持久化确认后清理**：宿主监听原生会话的 `session/event`（`user/message`）并调用 `sessions.flush` 确认事件落入 JSONL 日志后，才将该批次标记为 `committed` 并从待发背景表中移除。执行期间新收到的群消息保留到下一批次；一旦输入已确认保存，即使后续模型推理或发送失败，也不会在下次回复时重复附带旧背景。
- **崩溃与重启恢复**：插件启动时扫描所有 `claimed` 批次，通过只读句柄核对原生会话日志中的 `(sessionId, messageId, batchId)`。已写入日志的批次直接确认清理，未写入的批次释放回背景窗口（保留最近 100 条）。

## 群聊图片与引用展开

- **异步展開与哈希缓存**：入站消息先同步登记附件占位，随后在后台展开回复引用（`get_msg`）与合并转发记录（`get_forward_msg`，最多递归 2 层、20 次请求），并将图片与图片表情下载到 `<profile>/data/dsh-synapse/temp/imgs/<sha256>.<ext>`（支持 PNG、JPEG、GIF、WebP，单图上限 20 MB）。
- **按需读图**：送入模型的文本仅包含本地图片绝对路径（如 `[图片: /path/to/hash.png]`）或普通 QQ 表情文字标识（如 `[QQ 表情 14]`），由模型按需调用宿主的 `read_image` 工具读取，避免无条件编码 Base64。下载失败时记录错误类别并替换为 `[图片下载失败:<id>]`，日志中不记录带签名的原始 URL。
- **过期清理与引用保护**：图片缓存默认保留 7 天。处于待提交窗口或正在执行的批次会通过 `image_refs` 与 `image_pins` 表锁定对应图片，执行完毕且超过保留期后才会删除文件。

## 概率回复与持久化词云

- **双开关与触发优先级**：概率回复需全局开关与群开关同时开启。开启后，@机器人与关键词继续直接触发，其余普通消息按概率判定（覆盖原有的 `requireMention=false` 全量触发行为）。机器人自身、配置的 `botUsers`、AI 忽略名单、命令（`/!！` 开头）、空消息、纯表情、图片表情和纯网址不参与概率触发；普通图片可正常参与。命中屏蔽词的消息跳过概率回复，但仍记入背景窗口并刷新真人活跃时间。
- **词云工作线程**：词频统计运行在独立的 `worker_threads` 中，按群、发送者与分钟桶持久化在 `cloud_counts` 与 `cloud_documents` 表中。
  - 使用 `Intl.Segmenter("zh-CN")` 分词，剔除网址、路径、@提及、纯数字与停用词，单条消息内相同词只计 1 次。
  - 默认统计窗口为 48 小时，指数衰减半衰期为 18 小时。从至少出现在 3 条消息中的词里选出加权词频最高的 20 个词。
  - 每次判定先根据历史词云评估当前消息加成，再将当前消息写入统计。若命中多个热词，取最高权重计算加成（上限为配置的最大加成百分比，默认 200%）：
    $$\text{最终概率} = \text{clamp}\big(\text{round}(\text{基础概率} \times (1 + \text{加成})),\ \text{最低概率},\ \text{最高概率}\big)$$
  - 主线程对词云工作线程最多等待 100ms；若超时或锁冲突则自动降级为 0 加成，直接使用基础概率。

## 空闲消息调度

- **随机窗口与静默时段**：空闲消息同样需要全局开关与群开关同时开启。每个窗口在 `[windowMinutes - jitterMinutes, windowMinutes + jitterMinutes]`（默认 15–45 分钟）内随机抽取一次到期时间。每分钟检查一次；处于静默时段（默认 `Asia/Shanghai` 的 `00:00–09:00`）、群忙碌、冷却中或达到限额时直接跳过。
- **掷骰与随机延迟**：窗口到期且满足条件时，按配置的命中概率（默认 25%）掷骰一次并立即生成下一窗口。未命中则继续等待下一窗口；命中后进入 `delayMinSec`–`delayMaxSec`（默认 30–80 秒）的随机延迟。
- **真人打断与系统身份**：延迟期间若群内收到有效真人消息，立即取消本次待发空闲事件并重置空闲窗口。延迟到期并再次通过条件检查后，通过 IPC 通知 Bot 提交系统消息 `[系统来源，非管理员] 好久没在群里说话了，说点什么吧`，固定使用非管理员身份。重启会取消未发出的延迟事件，不会补发停机期间错过的窗口。

## 冷却、限额与忽略名单清理

- **冷却与配额计算**：Bot 每次成功发送群消息（通过 IPC 与 HTTP 双重通知去重）或提交自动任务都会刷新冷却时间。概率回复受每分钟、每小时滚动窗口限额约束；空闲消息受每小时滚动窗口及配置时区自然日（支持夏令时边界）的每日限额约束。
- **忽略名单清理**：修改「对话行为」中的 AI 忽略名单或「其他机器人 QQ 号」会通过 IPC 热更新到 Bot，并立即从 SQLite 背景窗口与词云分钟桶中剔除这些账号尚未提交的记录；已进入原生会话历史的消息以及命令、自动卡片、Discord 桥接功能不受影响。
